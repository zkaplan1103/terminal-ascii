
FARM ANIMALS SPRITE MINI-PACK

~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Thanks for downloading!
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

This is a small collection of farm animal sprites for use in your pixel-art games.

These sprites are intended to be decorative animations: useful for populating farm or 
village areas with some NPC animals.

Each animal sprite has two diagonal-facing directions, arranged in a way that create 
four directions. This allows them to move around as NPCs without needing a four-directional 
animation as might be desired for playable characters.

Some animals (horses, cows, bull) have an additional idle animation for eating grass.

The animals included in this set are:

- Dogs (4 color variants)
- Cats (4 color variants)
- Horses (4 color variants)
- Cow
- Bull
- Pig
- Piglet
- Sheep (wool and sheared, 2 color variants)
- Goats (2 color variants)
- Baby Chick
- Chickens (2 color variants)
- Turkey

~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Additional Information:

- Not specific to any individual art style; these sprites have a full-color style, intended 
  to work with - Elements, Omega Modern, or any other variety of styles by other artists
- Sprite sheets are organized in groups of 8, compatible with RPGMaker
- Includes versions for RPGMakers VX, VX Ace, MV, and MZ
- OK to use in commercial projects without any engine limitations
